# Smart Bench Power Supply

A dual-channel bench power supply built with upcycled components, featuring Arduino-based temperature/humidity monitoring, 16x2 I2C LCD status display, and automatic PWM fan cooling.

## 📌 Specifications
- **Input:** 19V 3.42A (ASUS Adapter)
- **Channel 1 (Buck):** XL4015 (Adjustable Voltage & Current)
- **Channel 2 (Boost):** MT3608 (High Voltage Output)
- **Control Unit:** Arduino Nano + DHT11 Temp/Humidity Sensor
- **Status Display:** 16x2 I2C LCD Display
- **Power Display:** Volt Meter / Ammeter Panel
- **Cooling:** Smart PWM Fan Control System via Dual MOSFET Module
